# KaosKaki Privacy Policy

_Effective date: 29 October 2026_

KaosKaki ("the app") is an open-source SOCKS5 proxy server for Android, published by the KaosKaki
developers (https://github.com/n0z0/cumi).

## Summary

**KaosKaki does not collect, store, or share any personal data.** The app has no accounts, no ads,
no analytics, and no crash reporting, and it never sends data to the developers or to any third party.

## What the app handles

| Data | Where it stays | Purpose |
| --- | --- | --- |
| Proxy settings (port, optional username and password, power option) | Stored only on your device in the app's private storage | To run the proxy the way you configured it |
| Network traffic of devices you connect to the proxy | Relayed directly between the connected device and the destination; never inspected, recorded, or stored | Providing the proxy service you started |
| Activity log (client IP address, destination host and port, amount of data, duration) | Kept only in memory on your device; cleared when you clear it or the app closes | To show you what is using the proxy |
| Device network addresses | Read on your device to display them | To show where the proxy can be reached |

None of this information leaves your device except the proxied traffic itself, which goes only to the
destinations requested by the devices you choose to connect.

Android's cloud backup is disabled for the app, so your settings are not uploaded to backup services.

## Permissions

- **Internet / network state / Wi-Fi state**: to accept proxy connections and show your network addresses.
- **Foreground service and notifications**: to keep the proxy running in the background and show its status.
- **Wake lock**: optional, keeps the CPU and Wi-Fi awake so the proxy stays responsive with the screen off.

## Children

The app is not directed at children under 13 and does not knowingly collect data from anyone.

## Changes

Changes to this policy are published in this file in the project repository, with an updated effective date.

## Contact

Questions about this policy: open an issue at https://github.com/n0z0/cumi/issues

# Kebijakan Privasi KaosKaki

_Berlaku sejak: 29 Oktober 2026_

**KaosKaki tidak mengumpulkan, menyimpan, atau membagikan data pribadi apa pun.** Aplikasi ini tidak memiliki akun,
iklan, analitik, maupun pelaporan crash, dan tidak pernah mengirim data ke pengembang atau pihak ketiga.

- **Pengaturan proxy** (port, nama pengguna dan sandi opsional, opsi daya) hanya disimpan di penyimpanan privat aplikasi di perangkat Anda.
- **Lalu lintas jaringan** perangkat yang Anda sambungkan diteruskan langsung ke tujuannya, tanpa diperiksa, direkam, atau disimpan.
- **Log aktivitas** (IP klien, host dan port tujuan, jumlah data, durasi) hanya disimpan di memori perangkat dan hilang saat dihapus atau saat aplikasi ditutup.
- **Alamat jaringan perangkat** hanya dibaca untuk ditampilkan kepada Anda.

Pencadangan cloud Android dinonaktifkan untuk aplikasi ini.

Pertanyaan tentang kebijakan ini: buka issue di https://github.com/n0z0/cumi/issues
